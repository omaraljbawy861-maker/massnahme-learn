# MAßNAHME LEARN — Native Flutter app

تطبيق Android أصلي مستقل بواجهة عربية RTL وهوية كحلية وذهبية. هذا المشروع معزول في فرع native-flutter-app ولا يستبدل الموقع المنشور.

## البناء المحلي
1. ثبّت Flutter stable وDart 3.9 أو أحدث.
2. من جذر المستودع نفّذ: `bash mobile/tool/sync_curriculum.sh`.
3. نفّذ: `cd mobile && flutter create --platforms=android --org de.massnahme.learn .`.
4. نفّذ `flutter pub get` ثم `flutter run`.

## الموجود في المرحلة الأولى
- واجهة أصلية مستقلة وقائمة تنقّل سفلية.
- بيانات المناهج JSON تُنسخ إلى أصول التطبيق عند البناء لتعمل الدروس دون اتصال.
- متصفح مواد الصف التاسع وصفحات الدروس.
- أكاديمية ZFA مع 13 Lernfelder.
- تسجيل دخول وإنشاء حساب عبر مشروع Supabase الحالي.
- اتصال أولي بدالة free-chat الحالية.

## ما لم يُعتمد إنتاجياً بعد
مزامنة تقدّم الدروس، حفظ سجل المحادثات، تشغيل مكتبة الفيديو، وروابط تأكيد البريد/استعادة كلمة المرور تحتاج ربطاً واختبارات إضافية قبل اعتبار التطبيق جاهزاً للنشر العام.
