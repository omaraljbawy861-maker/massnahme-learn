هذه نسخة موسعة من المنصة التعليمية المجانية للتحضير الدراسي لمستوى ESA / Klasse 9.

المحتوى:
- 10 مواد دراسية.
- 216 فصلاً تعليمياً إجمالياً موزعة على المواد العشر، وفق ملفات المواد الحالية.
- تمت إضافة 90 فصلاً جديداً ضمن ثلاث وحدات إضافية لكل مادة من المواد العشر.
- الشرح الألماني هو الأساس، مع توضيح عربي مساعد.
- الفصول الجديدة تتضمن أهداف تعلم، شرحاً، مفردات، أمثلة محلولة، تدريبات مع حلول، واجبات، وأسئلة مراجعة تفاعلية.
- توسيع مختبر اللغات الألمانية والإنجليزية بمفردات وجمل ونصوص قراءة إضافية.
- المحافظة على نظام تقدم الطالب والتصميم والواجهة الحالية.

المواد:
Deutsch, Mathematik, English, Biologie, Physik, Chemie, Geschichte, Erdkunde, Politik und Wirtschaft, Arbeitslehre.

طريقة التشغيل على Windows:
1) فك ضغط الملف كاملاً.
2) افتح مجلد MASSNAHME_LEARN_VS_CODE_V1_4 في Visual Studio Code.
3) افتح index.html بواسطة إضافة Live Server.
4) لا تفتح index.html بالنقر المزدوج؛ ملفات JSON تُحمّل عبر fetch ويجب تشغيل خادم محلي.

ملاحظة تعليمية مهمة:
هذا محتوى تعليمي أصلي موسع للمراجعة والتحضير، وليس كتاباً مدرسياً رسمياً صادراً عن وزارة التعليم، ولا يضمن وحده استيفاء كل متطلبات الامتحان الخارجي. يجب مطابقة خطة Maßnahme ومتطلبات ESA الحالية مع المدرسة أو الجهة التعليمية في NRW. لم تُنسخ صفحات كتب ناشرين تجاريين.

ملاحظة المراجعة:
تم التحقق آلياً من صحة ملفات JSON، وعدم تكرار معرّفات الدروس، ووجود الحقول الأساسية والتدريبات والواجبات وأسئلة الاختبار، وصحة مؤشرات الإجابات، كما تم فحص صياغة JavaScript. فشل اختبار المتصفح الآلي بسبب منع بيئة التنفيذ من فتح localhost، لذلك لم أزعم إتمام اختبار نقر حي داخل المتصفح.

إعداد حسابات الطلاب وحفظ التقدم:
1) افتح مشروع Supabase المرتبط بالمنصة، ثم ادخل إلى SQL Editor.
2) نفّذ محتوى الملف supabase/schema.sql لإنشاء جدول student_progress وسياسات حماية الصفوف.
3) من Authentication > URL Configuration أضف عنوان الموقع المنشور إلى Site URL وRedirect URLs، وأضف أيضاً عنوان المعاينة/التطوير الذي تستخدمه عند الحاجة.
4) من Authentication > Providers > Email فعّل تأكيد البريد الإلكتروني، واضبط رسالة التأكيد لتعيد الطالب إلى عنوان المنصة.
5) اختبر إنشاء حساب ببريد فعلي، وافتح رسالة التأكيد، ثم سجّل الدخول.
6) جرّب بحسابين مختلفين: أكمل درساً بالحساب الأول، سجّل الخروج، ثم ادخل بالحساب الثاني وتأكد أن تقدمه مستقل.

تنبيه أمني وتشغيلي:
- لا تضع مفتاح service_role في ملفات الموقع أو GitHub؛ يستخدم المتصفح المفتاح publishable فقط.
- سياسات Row Level Security في schema.sql تقصر قراءة وتعديل كل سجل على صاحبه.
- يحتاج تأكيد البريد وروابط إعادة التعيين إلى إعدادات صحيحة في لوحة Supabase، ولا يمكن اعتبارها مفعّلة قبل اختبار الرسائل الفعلية.
- تحفظ المنصة التقدم المحلي لكل حساب بمفتاح منفصل، وتزامنه مع جدول student_progress عند توفر الاتصال.

المساعد الدراسي التفاعلي:
- أضيف قسم "المساعد الدراسي الذكي" إلى القائمة الرئيسية.
- يحتوي على مؤقّت دراسة قابل لضبط المدة، بدء، إيقاف مؤقت وإعادة ضبط.
- يدعم كتابة الأسئلة، وإملاء السؤال عبر الميكروفون في المتصفحات الداعمة، وقراءة الرد بصوت الجهاز اختيارياً.
- واجهة المحادثة تستدعي Supabase Edge Function باسم study-tutor.
- تم إعداد الدالة لاستخدام Gemini 3.8 Flash عبر Google Gemini API، بدلاً من OpenAI.
- استخدام Gemini يتوفر ضمن خطة مجانية بحدود استخدام؛ عند بلوغ الحصة المجانية قد تتوقف الإجابات مؤقتاً حتى تجدد الحصة.
- لا تضع GEMINI_API_KEY في ملفات JavaScript أو HTML أو مستودع GitHub.

تفعيل المجيب الذكي (مرة واحدة من جهاز عليه Supabase CLI):
1) ثبّت Supabase CLI وسجّل الدخول: supabase login
2) اربط المشروع: supabase link --project-ref edzuhinhxhoxxocfjvbu
3) أضف مفتاح Gemini كسرّ للخدمة: supabase secrets set GEMINI_API_KEY=YOUR_GEMINI_API_KEY
4) انشر الدالة: supabase functions deploy study-tutor
5) افتح المنصة وسجّل الدخول بحساب طالب، ثم جرّب سؤالاً نصياً. امنح المتصفح إذن الميكروفون لاستخدام الإملاء الصوتي.
ملاحظة: استدعاء الدالة يتطلب جلسة طالب مسجّلة الدخول. حدود الخطة المجانية تختلف حسب النموذج والمشروع ويمكن مراجعتها من Google AI Studio.
